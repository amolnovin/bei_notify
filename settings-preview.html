پیکربندی تلگرام

ربات را با @BotFather تلگرام بسازید (t.me/BotFather) و آن را ادمین کانال/گروه کنید. اگر سرور سایت داخل ایران است، از بخش «پراکسی» یا آدرس API جایگزین استفاده کنید.

شناسه عددی یا نام کاربری کانال با @ — برای گروه خصوصی، شناسه عددی را با «شناسه‌یاب» به‌دست آورید

خالی = api.telegram.org. برای دور زدن فیلترینگ می‌توانید آدرس یک سرور رله (Reverse Proxy) که روی سرور خارج از ایران دارید را وارد کنید.

💬

پیکربندی واتساپ (مسیر رایگان)

با درگاه‌های میزبانی‌شده (Green API / Ultramsg) کلاینت واتساپ روی سرور خود درگاه اجرا می‌شود — شما فقط REST می‌فرستید. اگر سرور داخل ایران است و درگاه فیلتر بود، از «آدرس API سفارشی» (رله) یا کارت پراکسی استفاده کنید.

🆓 مسیر ۱ — CallMeBot (رایگان، ساده‌ترین):
۱) شماره ربات CallMeBot را در واتساپ ذخیره کنید و پیام «I allow callmebot to send me messages» بفرستید — apikey رایگان می‌گیرید.
۲) apikey را در «توکن درگاه» و شماره خودتان را (با کد کشور) در «شماره مقصد» بگذارید — تمام! پیام‌ها به واتساپ خودتان می‌رسد.
🆓 مسیر ۲ — شماره تست رایگان متا (رسمی):
۳) در business.facebook.com اکانت بیزینس رایگان بسازید و از WhatsApp → API Setup «شماره تست» رایگان بگیرید (Phone Number ID + توکن).
۴) تا ۵ شماره را در بخش To تأیید کنید — ارسال به این شماره‌ها بدون قالب و بدون هزینه است.
نکته: شماره +98 پشتیبانی نمی‌شود؛ و برای سرور داخل ایران، آدرس رله یا پراکسی لازم است.
🌐

پراکسی — دور زدن فیلترینگ

برای سرورهای داخل ایران که به api.telegram.org دسترسی ندارند. پراکسی فقط روی درخواست‌های پیام‌رسان‌های انتخاب‌شده اعمال می‌شود.

اعمال پراکسی برای:
راهکارهای دور زدن فیلترینگ تلگرام:
۱) اگر سایت روی سرور خارج از ایران است، هیچ اقدامی لازم نیست — فیلترینگ فقط دستگاه‌های داخل ایران را محدود می‌کند.
۲) آدرس API جایگزین/رله (کارت تلگرام) — سرور شخصی شما خارج از ایران که api.telegram.org را پروکسی می‌کند.
۳) پراکسی همین بخش — مخصوص سرورهای داخل ایران.
۴) ثابت‌های سراسری وردپرس در wp-config.php (برای HTTP Proxy):
define( 'WP_PROXY_HOST', '1.2.3.4' ); define( 'WP_PROXY_PORT', '1080' );

API خارجی (REST)

هر سیستم بیرونی با POST به این آدرس پیام می‌فرستد (احراز هویت: Application Password):

https://your-site.com/wp-json/bei/v1/notify 
curl -X POST "https://your-site.com/wp-json/bei/v1/notify" \
  -u "USERNAME:APP_PASSWORD" \
  -H "Content-Type: application/json" \
  -d '{"text":"سلام","targets":["bale","eitaa"]}'
