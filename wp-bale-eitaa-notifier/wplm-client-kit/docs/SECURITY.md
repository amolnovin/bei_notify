# نکات امنیتی WPLM Client Kit

این کیت برای امنیت عملیاتی طراحی شده است، اما هیچ سیستم لایسنسی در PHP صددرصد غیرقابل دور زدن نیست. هدف، جلوگیری حرفه‌ای از استفاده غیرمجاز در سطح کاربردی است.

## موارد رعایت‌شده

- استفاده از HTTPS اجباری به‌صورت پیش‌فرض
- `sslverify => true`
- Nonce برای فرم مدیریت
- بررسی capability مدیریت
- sanitize و escape ورودی/خروجی‌ها
- cache وضعیت لایسنس برای جلوگیری از کندی
- عدم ذخیره اطلاعات حساس اضافی
- پشتیبانی از grace کوتاه هنگام خطای شبکه
- عدم دانلود مستقیم ZIP؛ دانلود فقط از لینک امن سرور فروش

## توصیه‌ها

- در نسخه نهایی `allow_insecure` را فعال نکنید.
- product_slug را در همه افزونه‌ها یکتا بگذارید.
- optionهای license/status را برای هر محصول یکتا تعریف کنید.
- امکانات اصلی افزونه را فقط بعد از `is_active()` اجرا کنید.
- فایل ZIP نسخه‌ها را فقط از پنل wp-plugin-market-manager منتشر کنید.

## امنیت لایسنس منیجر مرکزی

- صفحه مرکزی فقط برای کاربران دارای `manage_options` در دسترس است.
- هر عملیات ذخیره، بررسی یا حذف لایسنس با nonce اختصاصی انجام می‌شود.
- product_slug ورودی sanitize می‌شود و فقط افزونه‌های فعال و ثبت‌شده در runtime قابل مدیریت هستند.
- کلید لایسنس در option اختصاصی همان محصول ذخیره می‌شود.

## نسخه جداگانه لایسنس منیجر

با جدا شدن لایسنس منیجر، افزونه‌های محصول فقط کلاینت سبک لایسنس را حمل می‌کنند و عملیات مدیریتی متمرکز در افزونه مستقل انجام می‌شود. این کار سطح تداخل بین چند افزونه محصول را کاهش می‌دهد.
