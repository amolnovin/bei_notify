افزونه حرفه‌ای وردپرس برای ارسال خودکار پیام به بله، ایتا، تلگرام و واتساپ؛ با پل ایمیل سراسری، اتصال آماده به ووکامرس و فرم‌سازها، ربات شناسه‌یاب، پراکسی و رله برای دور زدن فیلترینگ و بروزرسانی خودکار.

== Description ==

این افزونه بر اساس مستندات رسمی [docs.bale.ai](https://docs.bale.ai) و [eitaayar.ir/api](https://eitaayar.ir/api/) ساخته شده و پیام‌های سایت شما را به کانال یا گروه بله و ایتا ارسال می‌کند.

**امکانات:**

* ارسال پیام متنی، تصویر و فایل به تلگرام، بله و ایتا
* ارسال به واتساپ به‌صورت رایگان: CallMeBot (پیام به شماره خودتان) و «شماره تست» رایگان متا (بدون قالب، تا ۵ شماره)
* درگاه‌های پولی Green API و Ultramsg برای ارسال انبوه (اختیاری)
* پشتیبانی از پراکسی (HTTP/SOCKS5) و آدرس API جایگزین/رله برای دور زدن فیلترینگ تلگرام در سرورهای داخل ایران
* پل ایمیل سراسری — هر ایمیلی که هر افزونه‌ای بفرستد همزمان به پیام‌رسان می‌رود (مثل سرویس پیامک)
* اتصال آماده با یک سوییچ: Contact Form 7 ، WPForms ، Gravity Forms ، Ninja Forms ، Fluent Forms ، فرم المنتور و سفارش جدید ووکامرس
* اطلاع‌رسانی انتشار نوشته جدید
* API خارجی (REST) برای ارسال پیام از سیستم‌های دیگر
* تابع عمومی `bei_notify()` برای استفاده در هر افزونه یا قالب
* ابزار «پیدا کردن شناسه عددی گفتگو»: خواندن شناسه با ارسال تست، دریافت گفتگوهای اخیر (getUpdates) و ربات پاسخگوی «شناسه شما» در بله و تلگرام
* پنل تنظیمات مدرن و واکنش‌گرا + دکمه‌های تست اتصال

== Installation ==

1. فایل zip را از «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب و فعال کنید.
2. به «تنظیمات ← بله و ایتا» بروید.
3. توکن و شناسه چت هر پیام‌رسان را وارد و ذخیره کنید (راهنمای ساخت ربات در همان صفحه).
4. اتصال را با دکمه‌های «تست اتصال» بررسی کنید.

== Frequently Asked Questions ==

= توکن ربات را از کجا بگیرم؟ =

بله: ربات `@botfather` داخل خود پیام‌رسان بله. ایتا: پنل ایتایار (eitaayar.ir) بخش API هر کانال، یا `@botfather` داخل ایتا. ربات باید ادمین کانال/گروه باشد.

= چطور فقط ایمیل‌های خاصی فوروارد شوند؟ =

در بخش «پل ایمیل سراسری»، فیلد «فیلتر موضوع» را پر کنید — هر خط یک عبارت که باید در موضوع ایمیل باشد.

= آیا برای ارسال انبوه محدودیت هست؟ =

بله نرخ ارسال تعاملی است. برای سقف بالاتر، بله API کسب‌وکاری دارد (گزینه داخل افزونه) و ایتا اعتبار روزانه در API «برنامه».

= شناسه عددی گفتگو را از کجا پیدا کنم؟ =

در تنظیمات افزونه بخش «پیدا کردن شناسه عددی گفتگو»: برای بله و تلگرام با دکمه «خواندن شناسه با ارسال تست» (اگر chat_id را با @username پر کرده باشید)، با «دریافت گفتگوهای اخیر» یا با «فعال‌سازی ربات پاسخگو» که با دکمه «شناسه شما» شناسه عددی را نشان می‌دهد. برای ایتا، شناسه عددی در پنل ایتایار است یا با ارسال تست به username/لینک دعوت خوانده می‌شود؛ username بدون @ هم به‌عنوان chat_id کار می‌کند.

= کدام کانال واقعاً رایگان است؟ =

تلگرام (با رله Worker)، بله و ایتا کاملاً رایگان‌اند. برای واتساپ دو مسیر رایگان وجود دارد: ۱) CallMeBot — با یک پیام فعال‌سازی apikey رایگان می‌گیرید و پیام‌ها به شماره خودتان می‌رسد (فقط استفاده شخصی). ۲) «شماره تست» رایگان متا (Cloud API) — بدون قالب و بدون هزینه تا ۵ شماره تأییدشده. ارسال اطلاع‌رسانی انبوه با شماره اصلی متا (Utility/Marketing) پیام‌به‌پیام هزینه دارد و شماره +98 هم پشتیبانی نمی‌شود.

= واتساپ فیلتر است و API رسمی آن پیچیده است؛ چطور بدون سرور پیام بفرستم؟ =

از درگاه‌های میزبانی‌شده استفاده کنید: Green API یا Ultramsg کلاینت واتساپ را روی سرور خودشان اجرا می‌کنند — شما فقط REST می‌فرستید. کافی است یک‌بار شماره واتساپ (غیرایرانی) را با QR لینک کنید. اگر درگاه از سرور ایران باز نمی‌شد، از «آدرس API سفارشی» (رله) یا کارت پراکسی استفاده کنید. گزینه سوم، Cloud API رسمی متا است که نیازمند قالب پیام و رله است.

= تلگرام فیلتر است؛ چطور پیام بفرستم؟ =

چهار راهکار (در خود افزونه پیش‌بینی شده): ۱) اگر سایت روی سرور خارج از ایران است هیچ اقدامی لازم نیست — فیلترینگ فقط دستگاه‌های داخل ایران را محدود می‌کند. ۲) «آدرس API سفارشی/رله» در کارت تلگرام — آدرس یک Reverse Proxy روی سرور شخصی خارج از ایران. ۳) کارت «پراکسی» — پراکسی HTTP/SOCKS5 فقط برای درخواست‌های API پیام‌رسان. ۴) ثابت‌های سراسری WP_PROXY_HOST و WP_PROXY_PORT در wp-config.php.

= سایر افزونه‌ها چطور از این افزونه پیام بفرستند؟ =

سه روش: ۱) تابع مستقیم `bei_notify( $text, $targets )` با گارد function_exists. ۲) هوک استاندارد `do_action( 'bei_send', $text, $targets )` — بدون هیچ وابستگی؛ اگر افزونه فعال نباشد فراخوانی بی‌اثر است. ۳) REST API در آدرس wp-json/bei/v1/notify. نمونه‌های آماده برای ۲۰+ افزونه معروف در فایل examples/integration-examples.php است.
